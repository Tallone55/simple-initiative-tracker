A tabletop initiative tracker built on gtk4 and PyGObject. Saves files in .csv format and tracks the essentials. Supports math expressions in number fields, along with dice roll syntax.

Signing key for validation is available at `packaging/public-key.asc` in the source code.
Drafted with copious AI assistance, released under MIT license.
